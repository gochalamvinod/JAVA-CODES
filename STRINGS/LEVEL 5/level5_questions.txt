Write a Java program that builds a simple word-frequency counter: it removes all punctuation from a paragraph using a regular expression, splits it into words, groups the words by their length and first letter, and reports how many words fall into each group, along with a check on whether any two different words in the paragraph happen to produce the same identifying number.
Write a Java program that builds a simple Unicode inspector: given any string (including ones with emoji), it prints how many "characters" versus how many actual Unicode symbols the string contains, flags any position where those two counts disagree, and lists the numeric code of each symbol boundary in the string.
