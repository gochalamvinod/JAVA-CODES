JAVA STRINGS - LEVEL 4 (REGEX & PARSING)
==========================================

Q1. Check if "12345" matches only digits using matches().
Input:  "12345".matches("\\d+")
Output: true

Q2. Remove all digits from "a1b2c3" using replaceAll().
Input:  "a1b2c3".replaceAll("[0-9]", "")
Output: abc

Q3. Count how many digit-groups exist in "abc123def456" using Pattern/Matcher.
Input:  Pattern.compile("\\d+").matcher("abc123def456") -> find() loop
Output: 2 (matches: "123", "456")

Q4. Split "one:two:three" by ":" with a limit of 2.
Input:  "one:two:three".split(":", 2)
Output: [one, two:three]

Q5. Join a List<String> ["Java","is","fun"] with a space using String.join().
Input:  String.join(" ", List.of("Java", "is", "fun"))
Output: Java is fun

Q6. Count tokens in "The quick brown fox" using StringTokenizer.
Input:  new StringTokenizer("The quick brown fox").countTokens()
Output: 4

Q7. Check palindrome ignoring case and spaces: "A man a plan a canal Panama".
Input:  s.replaceAll("[^a-zA-Z]", "").toLowerCase()
Output: amanaplanacanalpanama (true, is a palindrome)

Q8. Right-pad an integer using String.format with width.
Input:  String.format("%5d", 42)
Output:    42

Q9. Count vowels in "Programming" using a char array loop.
Input:  for(char c : "Programming".toCharArray())
Output: 3 (o, a, i)

Q10. Validate a simple email pattern using matches().
Input:  "vinod@example.com".matches("^[\\w.+-]+@[\\w-]+\\.[a-zA-Z]{2,}$")
Output: true
